How it works

From scratch

A freestanding C kernel with Lua 5.4 compiled directly into it. No libc, no userspace baggage.

Bare metal

Lua 5.4.8 runs directly on x86_64 hardware. The kernel boots via Limine UEFI and drops into a real Lua interpreter.

Modern desktop (soon)

A desktop environment that actually looks good. Not 2011 Ubuntu. Not TempleOS. Something modern.
